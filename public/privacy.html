Приложение «Мастерская свечей» · действует с 25 октября 2026 г.

Что это за приложение

«Мастерская свечей» — производственный журнал для мастеров свечей: замесы, заливки, склад материалов и отзывы покупателей. Приложение работает по адресу katarinafogel.github.io/candles.

Какие данные собираются

  • Мастера. При входе через Google или по почте — адрес электронной почты и имя из аккаунта Google. Всё, что мастер вносит сам: формы, материалы, замесы, свечи, список людей, которым подарены свечи, и заметки.
  • Получатели свечей. Отзыв, который человек отправляет по QR-коду: оценки, комментарий и, если он сам его указал, имя. Вход для этого не нужен. История горения хранится только в браузере получателя и уходит мастеру лишь вместе с отзывом.

Как данные используются

Только для работы приложения: чтобы мастер видел свои записи на всех устройствах и получал отзывы на свои свечи. Данные не продаются, не передаются третьим лицам и не используются для рекламы. Данные Google-аккаунта используются только для входа.

Где хранятся данные и кто их видит

Данные хранятся в базе Supabase (регион — Европа). Каждый мастер видит только свои записи и отзывы на свои свечи — это обеспечивается правилами доступа в самой базе. Получатель свечи видит только её название, инструкцию и имя мастера.

Удаление данных

Чтобы удалить аккаунт и все связанные с ним данные, оставьте запрос в разделе Issues репозитория проекта — данные будут удалены в течение 30 дней.
