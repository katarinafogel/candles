# Установка Google Apps Script для отзывов

Скрипт принимает отзывы со страницы получателя, пишет их в Google-таблицу, присылает письмо и отдаёт отзывы приложению мастера.

## 1. Таблица и скрипт

1. Создайте Google-таблицу, например «Свечи — отзывы».
2. В таблице: **Расширения → Apps Script**.
3. Удалите содержимое `Code.gs` и вставьте код из [`Code.gs`](./Code.gs). Сохраните (💾).

## 2. Токен и почта

1. Придумайте длинный случайный токен (например, 30+ символов из букв и цифр).
2. В редакторе скрипта: **Настройки проекта (⚙️) → Свойства скрипта → Добавить свойство**:
   - `TOKEN` — ваш токен;
   - `EMAIL` — адрес для писем об отзывах (необязательно: по умолчанию — почта владельца).

## 3. Публикация

1. **Начать развёртывание → Новое развёртывание**, тип — **Веб-приложение**.
2. «Выполнять как» — **Я**; «У кого есть доступ» — **Все**.
3. Нажмите «Начать развёртывание», разрешите доступ к таблице и почте.
4. Скопируйте **URL веб-приложения** (оканчивается на `/exec`).

> При изменении кода нужно делать **Управление развёртываниями → ✏️ → Новая версия**, иначе по старому URL работает старый код.

## 4. Подключение к приложению

- В приложении: **Настройки → Отзывы и QR** — вставьте URL и токен. Токен хранится только на этом устройстве и не попадает в бэкап.
- Чтобы страница получателя на GitHub Pages знала адрес скрипта, добавьте URL в репозиторий: **Settings → Secrets and variables → Actions → Variables → New repository variable**, имя `APPS_SCRIPT_URL`. Затем перезапустите деплой (**Actions → Deploy → Run workflow**).

## Что делает скрипт

| Действие | Кто вызывает | Что делает |
|---|---|---|
| `register` | приложение мастера, с токеном | записывает ИД свечи, название и инструкцию в лист «Свечи» |
| `candle` | страница получателя | отдаёт название и инструкцию по ИД |
| `feedback` | страница получателя | добавляет строку в лист «Отзывы» и отправляет письмо |
| `pull` | приложение мастера, с токеном | отдаёт отзывы новее указанной даты |

Дубли отсекаются по UUID отзыва, который генерируется на телефоне получателя.
